# 🍫 Chocolate Revenue and Sales Intelligence Report

An interactive Business Intelligence dashboard developed using Microsoft Power BI to analyze chocolate sales performance, revenue trends, product demand, and regional insights.

This project transforms raw sales data into meaningful business insights using data visualization, KPI tracking, and analytical reporting techniques.

---

# 📊 Project Overview

This Power BI dashboard helps analyze:

- Revenue performance
- Product-wise sales
- Unit sold analysis
- Regional trends
- Monthly business growth
- Customer purchasing insights

The dashboard is designed to support data-driven business decision-making through interactive visual analytics.
